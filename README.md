# Dev Toolbox · 开发者工具箱

一个干净、快速的开发者工具导航站。深色 / 浅色双主题，支持实时搜索、分类筛选与本地收藏，纯静态、零依赖、无后端。

## 特性

- **45 个精选站点**，覆盖 AI、代码调试、前端样式、设计素材、效率协作、文档学习、测试性能、部署托管八大场景
- **实时搜索**：按名称、描述、标签、分类模糊匹配；按 `/` 快速聚焦搜索框
- **分类筛选**：顶部胶囊标签一键切换
- **本地收藏**：星标收藏写入 `localStorage`，不联网、不上传
- **深浅色主题**：跟随手动切换并记忆偏好
- **单文件实现**：所有样式与脚本内联在 `index.html`，无构建步骤、无第三方依赖
- **响应式**：`auto-fill` 自适应网格，移动端单列

## 部署

站点托管在 **GitHub Pages**，主分支根目录直接发布：

```
index.html    # 全部内容（HTML + CSS + JS 内联）
README.md     # 本说明
```

访问地址：`https://<你的用户名>.github.io/<仓库名>/`

### 本地预览

直接双击 `index.html` 用浏览器打开即可，或起一个静态服务：

```bash
python -m http.server 8080
```

## 自定义

所有工具数据集中在 `index.html` 内的 `TOOLS` 数组：

```js
{ n: "名称", d: "一句话描述", u: "https://链接", c: "分类id", t: "标签" }
```

分类在 `CATS` 数组中定义，可自由增删；新增分类时在 `CATS` 里加一项并保持 `id` 与 `TOOLS[].c` 对应即可，无需改动渲染逻辑。
